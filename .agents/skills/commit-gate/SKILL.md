# commit-gate / SKILL

## 目的
- a3-ci-github 固有のコミットゲートを一つの責務境界で扱う。
- staged snapshot に対するリポジトリ固有ゲートの結果から、コミットへ進めるかを fail closed で判定する。

## 原則
- リポジトリ固有ゲートの適用条件、実行入口、終了条件はこのスキルに集約する。
- 各ゲートが利用する別スキルの処理は再定義せず、公開実行面を利用する。

## このスキルが所有すること
- リポジトリ固有ゲートの適用条件と実行入口
- 固定参照更新順序ゲートによる、実装準備と利用可能化の区別・接続先の証拠確認
- 共通 `git` の `local_gate_result` 契約に従う各ゲート結果の返却
- 成功、検証失敗、実行エラーの終了条件

## このスキルが所有しないこと
- git スキルが所有する基本コミットゲート、SDD 適用監査ゲート、スキルデプロイゲート
- `regression-test` スキルが所有する回帰範囲、実行順序、報告形式

## 実行時の姿勢
- ゲートの適用条件、順序、終了条件を他スキルへ分散させない。

## コミットフローへの引き渡し
- 固有ゲート結果を共通 `git` の `local_gate_result` 契約で返す。
- `commit author`、コミットメッセージ、push の有無、最終承認 payload は git スキルへ委譲する。

## 注意
- ゲート成功は staged snapshot に対する判定であり、未ステージ差分の品質を保証しない。
- ゲートが停止した場合は、対象差分や実行条件を変更せずに同じ手順を繰り返さない。

## トリガー＆アクション
### a3-ci-github でコミット前のリポジトリ固有ゲートを実行したい
- `references/run-repository-commit-gates.guide.md` の適用条件を確認し、該当するゲートを実行する。
- 成功、停止、判定不能、非適用を含む各ゲート結果を git スキルのコミットフローへ返し、後続へ進むかは git スキルの集約規則に委譲する。
